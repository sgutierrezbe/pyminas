# Archivo histórico

Este directorio conserva elementos obsoletos para consulta y trazabilidad. No forman parte del flujo activo de pyMinas.

- `HANDOFF.md`: guía antigua de despliegue.
- `antigravity-setup/`: utilidades de migración de una sesión anterior.
- `scripts-obsoletos/`: inyectores históricos que no deben ejecutarse.
- `skills-obsoletas/`: copias antiguas; las skills vigentes están en `.agents/skills/`.
